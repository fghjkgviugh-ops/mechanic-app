# Mechanic App

Мобільний застосунок на React Native + Expo. Головний екран — карта з твоєю поточною локацією.

## Як запустити

1. Встанови [Node.js](https://nodejs.org) (версія LTS).
2. Встанови на телефон застосунок **Expo Go** (App Store / Google Play).
3. У папці проєкту виконай:

   ```bash
   npm install
   ```

   ```bash
   npx expo start
   ```

4. Відскануй QR-код з термінала: на Android — через Expo Go, на iPhone — камерою.
5. Дозволь доступ до локації — і побачиш себе на карті.

## Що де лежить

- `App.js` — код головного екрана (карта + геолокація).
- `app.json` — налаштування застосунку (назва, іконка, текст запиту дозволу).
- `package.json` — список бібліотек, від яких залежить проєкт.
- `assets/` — іконки та картинки.
