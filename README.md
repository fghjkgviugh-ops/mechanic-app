# Гараж (mechanic-app)

Мобільний вебзастосунок (PWA) для обліку обслуговування авто.

## Можливості
- Кілька авто: марка, модель, рік, номер, VIN, пробіг
- Історія робіт і витрат: ТО, ремонт, запчастини, пальне, шини, інше
- Нагадування за пробігом та/або часом (масло, фільтри, страховка…) зі статусами «скоро» / «прострочено»
- Статистика витрат за категоріями та роками
- Резервна копія в JSON-файл і відновлення
- Працює без інтернету; дані зберігаються лише на телефоні

## Як встановити на телефон
1. Опублікуйте папку на будь-якому HTTPS-хостингу (наприклад, GitHub Pages: Settings → Pages → Deploy from branch).
2. Відкрийте посилання на телефоні:
   - **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
   - **iPhone (Safari):** кнопка «Поділитися» → «На екран „Додому“».

## Локальний запуск
```
python3 -m http.server 8000
```
і відкрийте http://localhost:8000

## Файли
- `index.html`, `style.css`, `app.js` — застосунок
- `manifest.webmanifest`, `sw.js`, `icon*.{svg,png}` — встановлення та офлайн-режим
